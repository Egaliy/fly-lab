# Fly Lab — how a fly reacts to our design

**[Open the study →](https://fly-lab-lovat.vercel.app)**

[![Fly Lab](preview.jpg)](https://fly-lab-lovat.vercel.app)

126 website concepts from our studio, run through a connectome-constrained model of the Drosophila visual system — plus a reliability audit of every metric. Which designs can a fly not look away from?

- 3D fly and scene in Three.js
- Each concept scored on event density, response, contrast and mid-roll hold
- Concepts ranked by attention or shown in sequence

**Stack:** Three.js, Vite, Playwright for capturing the concepts.

```bash
npm install
npm run dev
```
